Sobre o Projeto

O DescomplicaBusiness nasceu nos Trabalhos 01 e 02 da disciplina de Cloud Computing. No Trabalho 01 foi modelada a infraestrutura na AWS (VPC, EC2, S3, DynamoDB); no Trabalho 02, a aplicação CRUD de atendimentos foi containerizada com Docker e publicada no DockerHub.

Neste Trabalho 03, evoluímos para a operação do ambiente Linux: um container Ubuntu Server administrado por scripts Shell que automatizam atualização do sistema, instalação do Apache, criação da estrutura de diretórios, backup, deploy, monitoramento, gestão de processos, usuários/permissões e geração de relatórios.

Tecnologias

  • Linux Ubuntu 22.04 (Server)
  • Docker e Docker Compose
  • Apache HTTP Server
  • Shell Script (Bash)
  • GitHub e DockerHub
